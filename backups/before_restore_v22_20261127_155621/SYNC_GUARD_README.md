# 当前版本：BOX_SYNCGUARD_V23

新增全程双轮直行同步监督，TEST工程未改。每段保留各自起点，以沿命令方向累计位移之差比较，前进/后退统一处理。

差值大于5双沿时，在原PD和同步参考上将领先轮目标限制到当前共同目标的一半；差值大于12且持续150ms，先两轮制动，50ms速度窗都为0并保持100ms后，领先轮保持制动，落后轮沿原方向以最高12双沿/50ms、500ms柔和起步追赶。差值达到2以内立即制动，再次停稳复核；满足差值后恢复原500ms软起步。无反转，无总计数/起点/终点重置，不把同步停车作为任务完成。

只在双轮均运行的直行启用；单轮旋转、原PD参数、四组前馈、速度配置、标定表及终点提前制动未改。有限行程任一轮进入终点制动后退出监督，仍按原终点逻辑完成。原驱动/编码器/反向/超速等检查保留，不恢复堵转检测。

纠偏期间任务不消费超声边界数据，清空连续确认计数；恢复后只接受恢复时刻以后触发的新测距。超声硬件仍约60ms触发，绕角仍需30个连续面外点。U帧增加guard(0正常/1两轮刹车/2追赶/3停稳复核)、guardN(本段纠偏次数)、diff(本段有符号轮程差)，wait=SYNC。原单面拟合算法不变，本次未处理短面拟合不可信问题。

主机回归和新增同步测试通过，ARM编译通过。新增测试覆盖前后两个方向、左右任一轮领先、保留进度、外部停车、有限终点、故障中止、单轮转角排除；不能代替实车负载与打滑验证。
