# 双轮编码器定速 PID 测试

本工程已改为独立的轮速测试固件。上电时电机保持关闭；按 PD0 循迹键启动或停止。PD1 探测键在停车状态切换目标转速 40、60、80、100 RPM；PD15 核心板键在停车状态切换 AIR（架空）和 GROUND（上地）标签。两种模式使用同一组初始 PID 参数，用于直接比较负载对实测转速和 PWM 的影响。屏幕每 250 ms 刷新模式、目标转速、左右轮实际 RPM 与各自 PWM 占空比。FAULT 状态按 PD0 清除，再按一次启动。

电机使用 TIM1 的 PE9/PE11（左）和 PE13/PE14（右），20 kHz PWM；PD2 总使能。编码器使用 TIM4 PB6/PB7（左）、TIM3 PA6/PA7（右），四倍频 840 计数/轮圈。方向及计数沿沿用原小车工程。PC4 为驱动 nFAULT，低电平立即关闭电机。PID 每约 50 ms 更新一次，前馈加独立 PI 闭环；KD 已实现但初值为 0，以免编码器量化噪声造成输出抖动。KP、KI、KD、编码器符号及电机符号在 Core/Src/main.c 顶部可调。屏幕显示的 PWM 为向前驱动占空比，最大限制 95%。

初次通电先架空车轮、确认方向和 RPM 为正。若空转时 RPM 显示负值，程序会进入 FAULT；先核对对应的编码器或电机方向常量。车轮卡住或 PC4 报故障也会停机。上地测试时把车放在开阔处，先用 40 RPM。当前测试固件不含循迹或超声自动停车。

原舵机超声程序保存在 Core/Src/main_servo_tracker_backup.c.disabled。当前 .ioc 仍是旧舵机配置；不要直接用 CubeMX 重新生成代码覆盖手写的 TIM1/TIM3/TIM4 配置。编译并烧录 Debug/test_servo_pwm.elf。

## 60 RPM 负载排查

旧参数在 60 RPM 目标、40 RPM 实速时只有 0.14 + 60×0.004 + 20×0.003 + 0.25 = 0.69，即约 69% 最大输出。现已将积分上限 0.25 提至 0.60、KI 提至 0.012，PWM 上限提至 95%；目标默认仍为 60 RPM。屏幕中某轮 PWM 后出现 MAX，表示该轮已接近 95% 且速度仍低于目标 5 RPM 以上。此时应测量运行时的电机电源 VM_BAT、电池电压、DRV8833 nFAULT 与轮胎阻力；仅靠进一步增大 PID 数值不能突破电源或电机的物理极限。增加电池前应核对电机、驱动芯片和板上电源的额定电压，并只按电路设计的电池接口接入。

## 1.69 寸屏幕适配

已改为 ZJY169T-IG01 / ST7789V2 的 240×280 SPI 显示。核心板 FPC 引脚：PB3/SCL、PB5/SDA、PD11/CS、PD12/DC、PD13/背光。模块上的 RESET 由 RC 电路处理，不接 PD10。显示使用 RGB565、竖屏、GRAM 纵向偏移 20 像素；屏幕仍显示测试模式、状态、目标 RPM、左右轮 RPM/PWM 以及 MAX 输出限制提示。旧 128×160 显示版本备份于 Core/Src/main_wheel_pid_st7735_backup.c.disabled。

屏幕四角为圆角，文字布局已向内收缩约 20 像素，底部提示上移到 y=248，避免字母被圆角遮挡。
