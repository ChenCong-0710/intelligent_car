# find_box_and_shoot_cc：第一阶段扫描盒面与单轮粗调

## 姿态和坐标约定

用户确认的目标为：侧向探头垂直指向盒面、车体近似平行盒面。角度左正右负，前进编码器为正。

- 盒面中心偏左：舵机+90度/2400us；左轮制动，只让右轮后退，产生负车体转角。
- 盒面中心偏右：舵机-90度/500us；右轮制动，只让左轮后退，产生正车体转角。
- 若拟合盒面法线为phi：左侧target=phi-90度；右侧target=phi+90度。例：左侧法线+20度，右轮后退粗调-70度；右侧法线-20度，左轮后退+70度。

这个动作不是让车头正对盒面，也不是原来的双轮反向原地旋转。

## 扫描与边界几何

保留原37点、每点5度的+90到-90扫描。标定仍为左2400us、中1460us、右500us，中间按两段线性插值；第一点给1200ms稳定，后续点120ms，每点再有180ms采样窗口，至少2个新鲜有效回波。重复帧、舵机在途回波和过期回波不计入。

两侧边界必须由距离突变或连续缺失回波支持，不能把扫描极限、拟合子窗口边缘或单个丢失回波当边界。近400mm量程上限的丢回波也不直接视为盒边。一个面内孤立漏点允许跳过，不伪造测距。

两边界点先由r/theta转换为平面坐标，边界连线给出近似法线；区间内多个有效点继续做原有逆距离平面拟合，检查残差和法线一致性，拒绝明显混面或无依据的单点最近距离。最终采用面内拟合法线，另记录edgeNormal供对照。障碍物偏左/右依据边界点中点的横向位置，不能仅凭法线角的正负判断。

找不到可信两侧边界/盒面时以NO_FACE结束，不进行车体粗调。这是对有限盒面的识别检查，实际超声边缘反射和背景仍需实测。

## 电机移植与接口

portable/dual_motor/dual_motor.c/.h来源于TEST已验证的位置式PD封装，控制公式无积分。Core/Src/car_motion.c提供：

```c
car_motion_init(&car, left_counter, right_counter);
car_motion_tick_1ms(&car, left_counter, right_counter, driver_ok);
car_motion_start_straight(&car, +1, count_goal); // 两轮前进
car_motion_start_straight(&car, -1, count_goal); // 两轮后退
car_motion_start_pivot(&car, 0, -1, angle_deg);  // 左轮后退，右轮制动
car_motion_start_pivot(&car, 1, -1, angle_deg);  // 右轮后退，左轮制动
car_motion_stop(&car);
```

接口也支持单轮前转。启动/停止及状态读取要与1ms中断互斥；不能运行中切换命令。本轮任务仅调用对应的单轮后退接口，前后直行接口供后续阶段使用。

- 直行：40个A相双沿/50ms；沿用TEST最新平缓计数差同步，目标到点后300ms渐停。
- 单轮粗调：34个A相双沿/50ms；500ms柔和起步，独立位置式PD，到计数阈值立即制动，另一轮全程制动，无终点反转补齐。
- 左轮标定点：0/30/60/90/120度 -> 0/175/407/611/814计数，中间分段插值；右轮保留90/95修正比例，90度约611计数。
- 左30度175是最新修正候选，左右90度用户已确认；不同角度和后退方向的实际转角不应假定全部已验证。actual显示的是编码器/标定估计角度，不是航向传感器实测。

编码器改为A相双沿捕获中断，B相仅判方向：左TIM4 PB6/PB7，右TIM3 PA6/PA7。TIM6固定1ms取计数并更新控制/终点，速度窗口50ms；驱动改为与TEST相同的驱动/制动PWM。原PI积分、四倍频840和130mm旧轮距不再参与速度控制或终点判断。现有标定名义轮距132mm、轮径43mm；不靠修改轮距掩盖误差。

## 第一阶段状态机

```text
SCAN -> FIT -> SIDE_SETTLE -> TURN -> BRAKE -> LOCK -> DONE
             侧向稳定1200ms   PD计数完成   侧向新回波验证
```

拟合完成后先把舵机设为对应侧向，并等待稳定，再发起一次单轮后退。运动是否完成由PD控制器的真实计数与停稳状态反馈决定，不用主循环时间或估计角度提前结束。LOCK验证侧向40..400mm新鲜回波；没有有效回波时报SIDE_NO_ECHO。所有失败/取消状态禁止再发起动作。

沿用原启动策略：未来烧录后复位会自动执行一次扫描和粗调；PD0按住20ms中止，取消后复位才能重扫。看门狗复位会停在故障状态，不自动重新运动。激光/蜂鸣器保持关闭。
