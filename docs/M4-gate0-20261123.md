## 4. 这次落地的固件修改（`Control/line_follower.{c,h}`、`Core/Src/main.c`）

1. **LEG 侧距连续采样**：`PROBE_LEG,seg=PROX`（50 ms 取、100 ms 打）与 `PROBE_LEG,seg=PROX2`（DRIVE2 统计 `pred/n/face_n/face_h/h_min/h_max`）。宽面转完后舵机本来就在 `side_us`，这一步只是把读数留下来。
2. **探测结束保持侧视角 10 s**：`probe_hold_until`，不再立刻断电/回正。
3. **SIDE_LOCK 容差 40 → 70 mm**：实车 TURN_PAR 后 `h-(ρ+pan_x)` 系统性 +28~+58 mm（转向平移），40 mm 把正确的锁面判成失败；70 mm 仍能挡住 `h=93` 的挡块（Δ85）。
4. **宽窄判据 130 → 100 mm**：全部历史侧扫 宽面 109.5~187.4、窄面 43.6~79.7，130 会把 h≈200 处的宽面（118.5）误判成窄面。
5. **SIDE_LOCK 测斜改成「沿面 60 mm 平移两点法」**（替代已废弃的 5° 旋转法）：
   - 前进 60 mm（80 mm/s）→ 停 200 ms → 量 h2 → **退回原点** → 按 `corr=atan2(h2-h1, 60)` 原地转正 → 量 h3；
   - 只对第一面做（第二面 50 mm 窄面，前后 60 mm 会出界）；
   - 1.5 s 内走不到一半判「卡住」，`warn=6`，跳过测斜继续；
   - 60 mm×tan(13.7°)=14.6 mm，是 h 噪声（±3 mm）的 4 倍。
6. **锁定 h 的取值**：`h1/h2/h3` 里取最接近 `pred` 的那个；`h3` 出 [80,350] 而 h2 有效时先用 h2（`warn=7`）。
7. **转角速度 35 → 50 mm/s**，`TURN_PAR` 超时 3 s → 6 s；**取消转前「后退 20 mm」**（`LF_TURN_PAR_BACKUP_RHO_MM=0`，现场判定无用）。
8. **诊断日志补齐**：
   - `PROBE_FACE` 现在在 `AIM→TURN_PAR` 成功路径也打（此前只打失败路径，导致「为什么不是 90°」看不到 φ/ρ）；
   - `PROBE_SIDE_LOCK` 追加 `h3=`、`warn=`；
   - `PROBE_SIDE_FAIL` 打 `lock_stage=`（原来打的是扫描 stage，恒为 0）。

> 关于「转向不是 90°」：`cmd = φ − 90`。11:54 的 `phi=5.38` → `cmd=-84.6`；11:50 的 `phi=-0.64` → `cmd=-90.6 / ach=-90.9`。也就是**车摆正时转角就是 90°**；此前 76°/103° 都是 AIM 实测到车头相对箱面斜了 13~16°（上一轮结束时车被带偏、这轮只平移回位没转正）。

## 7. 后续修订（2026-11-23 17:00）

本文件是 Gate 0 的**实车记录**，不再改动结论；这里只补两条后来发现、会影响分数的问题：

1. **§4.5 的测斜死区 1.5° 偏小**：60 mm 基线的角度噪声 σ≈1.3°，平行时也会转一下。
   M4e **只改值：死区 7°**；另外按实测面宽选基线（宽 60 / 窄 30），窄面不再跳过。见 [M4e 计划](../../M4e计划_遍间航向闭环.md)。
2. **`SIDE_MOVE` 到位后还会按漂移量原地转一次**（`side_move_corr_rad` → `probe_turn_to`）：
   `probe_side_verify=1` 时后面复测能拉回来，**`verify=0`（Gate 0 现场就是关的）时转完直接发射**，
   光斑偏 `h·tanε`：7°→22 mm、12°→38 mm，而 50 mm 窄面半宽只有 25 mm。
   M4e 把这条转向**直接删掉**（不在别处补——扫描与发射之间本来就不该有任何转向）。
   同时 `h_leg = side_h + side_k·s_m` 里的 `side_k` 是 8 点滑窗的钳位值（≠倾角），应改成 `h_leg = side_h`。

> 这两条都不改 Gate 0 的"通过"结论：它们影响的是 4 面循环的得分稳定性，不是 Gate 0 的门禁项。
