# M4f：AIM 改 0~180° 全行程 + 角域边界法（含打靶精度未解问题交接）

> 日期：2026-11-24。状态：**代码完成、单测 38/38、已烧录（Debug-make）**；但**打靶精度仍未解决**（见 §6），
> 交接时请先读 §6 与 §7。
> 改动面：`Control/line_follower.c` / `.h` / `Core/Src/main.c` / `tests/test_controller.c`（+172/−24）。

---

## 0. 一句话

把 AIM 从「±30° 扫掠 + `1/r` 平面拟合」改成「**0~180° 全行程扫掠 + 两条棱边的角域边界法**」，
目的是修掉 AIM 输出的法线 φ 偏 4~18°（它让 TURN_PAR 后车头与面不平行，进而把侧扫的 h、w 全带偏）；
同时把「扫描结束二次微调」重新打开，死区按现场要求收到 **±1.5°**。

**这一边（摆正/测面）解决了；光斑仍稳定偏向小车后方 → 得分 2~4 分，原因尚未确定，见 §6。**

---

## 1. 为什么改 AIM（证据链）

| 证据 | 数值 | 含义 |
| --- | --- | --- |
| AIM 扫掠半幅 `sweep_us` | 300 µs = ±30° | 150 mm 面在 163 mm 处只张开 **±24.7°**，端点已在面外 |
| 端点回波 | 背景墙 500~900 mm | 端点 `r` 被拉长 → 最小二乘斜率被带偏 |
| 侧扫长基线反推的残余偏航 ε̂ | 8 次实测：−13.0 / −9.1 / −10.2 / +4.6 / −4.3 / −18.4 / −6.4 / −11.8° | 侧扫 σ 只有 0.6°，所以这些不是噪声，是**真偏** |
| 后果 | 车头与面不平行 4~18° | 侧扫 `h` 沿面漂 40 mm、`w` 不稳、`side_k` 永远撞 ±0.25 钳位 |

> 注意：`side_k` 撞钳位**不能**当作偏航证据（8 点环只有 24 mm 基线、噪声 ±15 mm），可靠的是长基线回归。

## 2. 改了什么

### 2.1 扫掠参数

| 参数 | 旧 | 新 | 理由 |
| --- | --- | --- | --- |
| `probe_sweep_us` | 300（±30°） | **900（600~2400 µs = 0~180°）** | 现场要求；且旧幅已超出面宽 |
| `probe_aim_ms` | 3000（每段） | **5000** | 180° 要 ~38 个点（每点 120 ms） |
| `probe_step_us` | 60 | **30** | 点数上限 64 |
| `LF_PROBE_SCAN_MIN_DWELL_MS` | 180 | **120** | 每步只转 4.9°，60 ms 足够停稳 + 60 ms 一帧 |
| `LF_PROBE_SCAN_SKIP_MS` | 120 | **60** | 同上；否则点数被驻留压到 20（步长 9.5°） |
| `LF_PROBE_SCAN_POINTS` | 41 | **64** | 数组容量 |
| `LF_PROBE_AIM_SETTLE_MS` | 150 | **400** | 首点可能要甩 90°，150 ms 走不到位 |
| `probe_sweep_us` 校验上限 | 600 | **900** | 否则 `set` 会被拒 |

实际点数 38（受 `max_n = sweep_ms/min_dwell` 限制），步长 **4.9°/点**。

### 2.2 角域边界法（`probe_boundary_normal()`）

```
① 选段：最近连续段（沿用 probe_fit_normal 的 run 切分，跳变阈值 40 mm）
② 两条边界角 = (最后一个面内帧 + 第一个面外帧) / 2        ← 与侧扫同一条判据
③ 减去半个波束角 γ：回波是**波束边缘**碰到棱边才消失的，所以跳变带中点比真实棱边向外偏一个 γ
   实测：−边渐变带 49 mm / 190 mm = 14.8° ≈ 2γ（γ=7.5°）—— 模型与实测吻合
④ 面内点（首尾各让一个）做**笛卡尔主轴拟合（TLS）**得到面直线
   —— 这是精度提升的真正来源：θ 是精确量，只有 r 有噪声；不再像 1/r(θ) 那样被端点拉偏
⑤ 两条边界射线 × 面直线 = 两个棱边点
⑥ 切线 = P_R − P_L；法线 = 切线法向；宽度 = |P_R − P_L|；中心 = (P_L+P_R)/2
```

- 法线角与平面拟合同一约定（`face.phi` = 原点到面直线垂足的方向 = `1/r` 最大的方向）。
- **兜底**：只有一条边在行程内 / 宽度 ∉ [25,200] / 站距 ∉ [50,400] / 边界射线几乎平行于面 → 退回原来的 `1/r` 平面拟合，行为与旧版一致。
- 两遍独立扫掠（正/反向）仍按原逻辑合并（\|Δφ\| ≤ 25° 取平均），舵机回差被抵消。

### 2.3 二次微调重新启用

| 项 | 旧 | 新 |
| --- | --- | --- |
| `LF_SIDE_YAW_ENABLE` | 0（编译掉） | **1** |
| `LF_SIDE_YAW_DEADBAND_DEG` | 4.0 | **1.5** |

触发条件不变：长基线样本 ≥30、跨度 ≥50 mm、`probe_side_width_ok(w)`、\|ε̂\| ∈ (1.5°, 20°)。
触发后**必须**退回原扫描原点重扫（性质①的前提），这一点由 `probesideyawfix` 与 `probemovenoturn` 两个用例守着。

## 6. 未解决问题：打靶仍然不精准（交接重点）

### 6.1 现象

- 四面全流程能跑通（145.7 s、四面 `SIDE_LOCK ok=1 warn=0`、三次 LEG 都 `stop=E`）。
- 但**得分低且稳定偏一侧**：宽面按 5 等分（每带 30 mm，分数 2/4/6/4/2），
  现场先是 **4 分**、后是 **2 分**；光斑**恒定偏向小车后方**（站在车后看靶纸 = 打在左侧）。
- 换算：**6 分 = 离面中心 0~15 mm；4 分 = 15~45 mm；2 分 = 45~75 mm。**

### 6.2 已经排除/确认的

| 项 | 结论 | 依据 |
| --- | --- | --- |
| e（激光与超声横向偏距） | **≈0**（两个器件装在一起） | 现场确认 |
| 侧扫中点算错 | 不太可能 | 19:54 那次两遍独立扫描中点只差 **9.1 mm**、`w=145.5`（真值 150） |
| 停车位置不可复现 | 不成立 | 同上，可复现到 ~10 mm |
| 点数太少/采样太稀 | 不是主因 | 3 mm/帧、65 点；`w` 与真值差 4.5 mm，说明两条边被**一致**检出 |
| 扫描↔发射之间被转身 | 这版不会（`SIDE_MOVE` 的转身已删，微调必须重扫） | 代码 + 单测 |

### 6.3 剩下唯一的候选（45~75 mm 的固定偏置必须有固定来源）

停车/测量可复现到 ±10 mm，而偏置是 45~75 mm，**只能是「声波瞄准的点」与「激光打中的点」之间的固定夹角 α**：

```
光斑偏移 = h · tanα      h=176~192（四面几乎相同）→ 看起来就是常数、永远同一侧
45 mm → α=13.4°    60 mm → α=17.6°    75 mm → α=21.6°
```

性质①（扫描↔发射同一云台角）**管不到它**：性质① 保证的是「同一个云台角」，管不到「云台上两个器件彼此不平行」。
手册 §17.8 第二行写的就是这个（「光点整体平移 = 安装角歪」）。

### 6.4 判定方法（下一步第一件事，约 10 分钟）

同一面、**两个站距**（h≈190 与 h≈120）各静态打一次，量光斑到盒子左/右边沿的距离 L：

| 结果 | 结论 | 修法 |
| --- | --- | --- |
| 偏移随 h 成比例缩（189→120 时缩到 63%） | **角度 α** | 发激光时舵机加 `10·α` µs（舵机标度已实测 10 µs/°，见下）；扫描仍用 2400，性质① 不动 |
| 偏移基本不变 | **位置**（靶纸偏心 / 装配间距） | 平移泊车目标 `side_target` |

静态打靶命令（**不驱动电机**，车不动）：

```
outtest servo 2400 30000     # 舵机压到侧视 90° 并保持
outtest laser 1 10000        # 再点激光 10 s（servo_enable=0，舵机保持 2400）
outtest stop                 # 结束
```

舵机标度互证：`PROBE_LOCK,servo_us=1443,center_us=1500,angle_deg=-5.7` → (1443−1500)/10 = −5.7° ✓。

### 6.5 2026-11-24 21:05 现场结论：同轴 → α/e 排除，改成「车头 Δψ」补偿（已落地）

现场确认 **激光与超声同轴**，靶纸/箱子没问题，因此 §6.3 的 α/e 不成立；剩下的是**扫描后车头又漂了**：

- `SIDE_MOVE/复测` 原来固定用 `phase_start_rad`（SIDE_MOVE 的相位起点 = **扫描结束**时的车头），
  而 `s_m` 是相对 **side_origin_rad（扫描起点）** 量的 → 扫描期间的漂移被当成基准锁住，激光沿 Δψ 打出去；
- 改成 `probe_drive_signed(c, spd, c->side_origin_rad, dt)`（侧扫/开位/复测/搜索），TURN_PAR 倒车保留 `phase_start_rad`；
- `LF_PROBE_LASER` 再补一次残余：`|heading − side_origin_rad| > LF_SIDE_YAW_DEADBAND_DEG(1.5°)` 时
  `servo_us = side_us − 10·Δψ`（限幅 600~2400）；补偿换了角就 **停 400 ms 再开激光**（每面只认第一次命中）。
  1.5° 在 h=189 时只有 5 mm，落在宽面 6 区 ±15 / 窄面 4 区 ±8.3 内；小于死区不拧舵机、不白等。
- `side_us=2400` 是舵机上限：正补偿会被截断，现场先把 `probe_side_us` 降到 **2350/2300** 留余量（§17.2 已验 2200~2400 可用）。
- 顺带把 `update_odometry` 改成中点积分（`θ + Δθ/2`）。

### 6.6 若确认是位置

- 先量靶纸中心是否就是面的几何中心（到左/下边沿各 ≈75 mm）；
- 若不是：**先把靶纸贴正**（换纸就得重标，所以最好先做机械对中）；
- 若是：把偏置加到两处 `side_target` 赋值上（`SIDE_SCAN` 结束、复测结束），**不要**写进 `face.s_m`（否则复测的 8 mm 一致性判据会被破坏）。

## 7. 下一步清单（按性价比）

1. **标定光斑偏置**（§6.4）——唯一能系统性补回的偏差，可能一次拿回 2~4 分/面。
2. **确认靶纸对中**（10 分钟机械）。
3. **跑一面看三件事**：`PROBE_AIM_BW` 的 `bw/w`、`PROBE_SIDE_YAW` 的触发率、总时长。
4. 若窄面也要 6 分：中点散布要从 ±10~15 mm 压到 ±5 mm —— 方向是「两遍扫描总是取平均」
   （`LF_SIDE_VERIFY_TOL_MM` 8→15，让 9.1 mm 这种差异取平均而不是丢弃初测）**或**改边界判据为单调抬升；
   单靠加点数无效（渐变带里已有 16 个点）。
5. 时间紧时：`LF_SIDE_YAW_DEADBAND_DEG` 1.5°→2~3°，或只在窄面复测。
