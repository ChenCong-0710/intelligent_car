## 3. 五条改动与证据

### 3.1 DRIVE2 从「死算 162 mm」改成「认到面就停」

**问题**：原地转 90° 时整车被地面拖着走 0~70 mm，而里程计 `ds = .5*(ΔL+ΔR)` 在对称转时**恒为 0** —— 编码器完全看不见这段位移。落地误差实测 −106…+174 mm（`h_pred` 对实测：202/183/97/225/257/370）。

**改法**：侧距连续 2 帧进 `h_ref±70` 即认为下一面已进侧视 → 停在「面近边 + `d_B/2` + 波束足印」（窄面 ≈+27 mm）；死算 `L2` 只当上限。

**证据**：`PROBE_LEG,seg=DRIVE2,len=109.0,ach=109.1,stop=E,s=61` —— 命令 109 mm（事件 + 补足），认面发生在 61 mm。三轮全部 `stop=E`。

### 3.2 站距锁定首面 `h_ref`

**问题**：`L1 = w/2 + pan_x + h + margin` 每面主动再远 20 mm，且用的是**本面**的 h（含测量误差）→ 站距 160 → 206 → 298 逐面外扩。298 mm 时 150 mm 宽面只扫出 58 mm 跨度，`w = 58 − 2·39 = −20.3`（两条边反序）→ catastrophic → 停机。

**改法**：首段 LEG 锁存 `h_ref`（首面实测），之后恒用 `L1 = w_nom/2 + pan_x + h_ref`，删掉 margin。

**证据**：修复前 4 面站距 170 / 215 / 202 / 271；修复后 176 / 192 / 176 / 189。

### 3.3 SIDE_LOCK 去掉 `|h−pred| ≤ 70` 相对门禁

**问题**：`pred` 是**第一面 AIM** 的 `rho+pan_x`，全程不更新。AIM 停车差 20 mm，第二面的生死就变：21:36 实测 231 拿 155.2 比 → 差 75.8，超 5.8 mm 停机；21:56 实测 298 拿 229 比 → 差 69，擦边过。而 LEG 落点误差 −106…+69 与「认错面」在数值上无法区分。

**改法**：只保留绝对量程 `h∈[80,450]`；超差只记 `warn=13`（诊断），照样进扫描。扫描的种子窗口用的是**实测 h**（自洽），所以站距偏大只会让激光远一点，不会扫错面。

**证据**：本轮四面 `warn=0`；22:42 轮第 4 面 `warn=13`（h=271 vs 期望 170）仍然打完了激光。

### 3.4 关闭扫描后的「二次微调」

**问题**：它用一次扫描的长基线斜率算残余偏航，然后原地转正、退回原点、再扫一遍。实测每次转完 `w` 都变差：152.9→140.3、64.2→74.3；22:33 更用一条只有 16 mm 的假边（`w=16.4`）算出 −18.4°，把车转了 18.4°，重扫一条边都没有，整面丢失。

**改法**：`LF_SIDE_YAW_ENABLE 0`（代码保留、开关关闭）。依据是**性质①**：扫描与发射同轴同角，残余偏航在光斑处自然抵消，本来就不需要为它转车。

**副作用**：每面少一遍扫描 + 两次原地转，单面省 ~5 s，也把「测量次数太多互相打架」这件事根除。

### 3.5 去掉 LASER 之后的 `w > 20` 停机门禁

**问题**：22:23 第 2 面复测扫出 `w=19.9`（4.4° 微调后拟合崩）→ 直接停机，整轮结束。而 LEG 用的是 **kind 的标称宽窄**（`LF_BOX_LONG/SHORT`），`probe_leg_current_kind` 只看 `box_first_kind` + 面序，**与实测 w 无关**。

**改法**：宽度不可信时退回本面此前可信的 `side_w_prev`（再不行用标称值），只记 `warn=12`，照常绕行。

### 3.6 附带：TURN_PAR 精度门禁 8° → 机构级 20°

`LF_TURN_TOL_DEG=8°` 会为 9° 的角度残差丢掉一整面，而扫描后续本就能容忍 ±20°。现在只有 `|ach−cmd| > LF_TURN_GROSS_DEG(20°)`（转不动/转反）才停机。

## 4. 日志判读速查

| 字段 | 取值 | 含义 |
|---|---|---|
| `PROBE_LEG,seg=DRIVE2,...,stop=` | `E` | 认面事件停车（正常路径） |
| | `L` | 一直没认到面，走满上限（窄面 = `L2+100`） |
| 同上 `s=` | mm | 认到面时的 DRIVE2 行程；与 `len` 相减即「补足段」 |
| `PROBE_SIDE_LOCK,warn=` | `0` | 正常 |
| | `10` | 静止一帧都没回波 → 用 LEG 行进中的面均值兜底 |
| | `11` | 执行过沿面搜索（每次前进 30 mm，最多 3 次） |
| | `12` | 宽度不可信 → 退回上次可信值（不影响绕行） |
| | `13` | 站距超出 `h_ref±70`（只诊断，不停机） |
| `PROBE_SIDE_LOCK,pred=` | mm | 面 0 = `rho+pan_x`；面 1~3 = `h_ref` |
| `PROBE_SIDE_FAIL` | — | 回波不可用且搜索 3 次仍不行 / 扫描找不到两条边（含重扫一次）/ 边界反序且重扫仍崩 |

## 5. 遗留与待办

1. **认面窗口中心不一致（1 行，未烧录）**：DRIVE2 事件用 `leg_h_expected + LF_LEG_MARGIN_MM`（=[120,260]），而 `face_n/face_h` 统计用 `leg_h_expected`（=[95,245]）。margin 已从 L1 删除，窗口应统一为 `leg_h_expected±70` = [100,240]。**行为影响仅限停车点 ±20 mm**；代码里已加 `TODO(下次烧录一并改)` 注释，等下次烧录带上。
2. **宽度实测散布 −22…+33 mm**（真值 50/150：窄面 28.2~67.2、宽面 132.3~183.2）。`w` 只用于判宽窄、不进控制；若要当指标，需先标定波束足印与斜入射回波特性。
3. **回 AIM 重试**（`LF_PROBE_REAIM`）与 **`probetour` 虚拟箱体** 仍未实现。
